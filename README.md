# 3D-Printed-Lens-Filter-Case
Open source case for storage of lens filters.

All parts were designed in OpenSCAD for a parametric approach allowing additional sizes to be easily generated and to custom fit your filter collection.

If you don't know how to use OpenSCAD/Customizer, don't worry.  The parts you're looking for are on [Thingiverse](https://www.thingiverse.com/thing:7312637) and [MakerWorld](https://makerworld.com/en/models/2506854-customizable-lens-filter-storage-case-v2).
